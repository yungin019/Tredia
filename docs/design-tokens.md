# Tredia Design Tokens

## Colors

- **Background Gradient**: `linear-gradient(180deg, #0B0E18 0%, #0F1321 55%, #111827 100%)`
- **Accent Cyan**: `#00B8FF`
- **Accent Aqua**: `#00FFC6`
- **Electric Blue**: `#5B8CFF`
- **Gold**: `#FFB74A`
- **Profit**: `#16E27C`
- **Loss**: `#F85C50`
- **Card BG (Glass)**: `rgba(255,255,255,0.06)`
- **Border**: `rgba(255,255,255,0.10)`
- **Text**: `#FFFFFF` / `rgba(255,255,255,0.85)` / `rgba(255,255,255,0.65)`

## Typography

- **Font**: `Inter` (fallback `DM Sans`)
- **Weights**: `400`/`500`/`600`/`700`
- **Headings letter-spacing**: `-0.01em`
- **Data labels letter-spacing**: `+0.01em`

## Radius

- **Cards/Modals**: `1rem`
- **Inputs/Buttons**: `0.5rem`

## Shadows

- **Neon**: `0 0 20px -6px rgba(0,184,255,0.35)`
- **NeonSm**: `0 0 12px -6px rgba(0,184,255,0.25)`

## Spacing

- **Card padding**: `px-6 py-4`
- **Grid gaps**: `gap-6`
- **Container max width**: `1200px`

## Motion

- **Page load**: `fade + scale(0.98 -> 1)` over `250-300ms`
- **Hover lift on cards**: `scale(1.02) + NeonSm shadow`
- **Button hover**: `gradient shift + inner glow`

## Charts

- **Axis color**: `rgba(255,255,255,0.65)`
- **Grid color**: `rgba(255,255,255,0.12)`
- **Line stroke**: `Accent color (cyan/gold), 2.5px`
- **Area fill gradient**: `10-15% opacity`
- **Tooltip**: `glass surface with accent title`
